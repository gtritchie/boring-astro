This was one of the first things I wrote for NeXTSTEP, a simple GUI front-end for the Unix `find` command.

I have no screenshots or source code for it, and couldn't find any hints of it in the old archives.

My recollection is that the top area of the window had assorted controls (checkboxes, text fields, etc.) where you chose the arguments for `find`, and then it ran the command and piped the output into a large text area in the bottom part of the window.

The next step (see what I did there) would have been to parse the output from `find` and display it in a more useful manner than just showing the raw output. I never got back to it.
