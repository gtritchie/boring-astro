I've been "coding" with Agentic AI at work and on personal projects, for over a year. In many ways, it has made software development fun again (if I ignore the huge disruptions to my industry, and the wild uncertainties it has introduced into business models, career paths, and the global economy).

I was a self-taught developer who started on the pre-Mac/PC home computers of the early 1980s, learning assembly language and interrupt tables and directly accessing video memory from books and magazines. From there I moved to DOS, where again I was doing low-level C and assembly code, and even wrote, on a random weekend, a primitive virtual memory manager that paged data using extended or expanded memory. I am sentimental about the days when I could learn something in great depth, and leverage that for years, referring back to the same physical books, and building stuff on top of that stable knowledge.

With the arrival of the internet, programming became less fun for me. Still exciting, still rewarding, blah blah blah, but never quite as fun. It was no longer possible to catch up. I suppose it's really that I felt smarter in 1990 because other than mysterious book titles at the computer book store, I wasn't constantly bombarded with proof of just how little I actually knew. My imposter syndrome runs deep in both professional and personal spaces.

Prompting LLMs comes naturally to me. I talk to them the way I used to talk to myself, except now things that would have taken me months ("I must learn this from first principles before I do anything tangible") happen in minutes.

My experience gives me (I hope) strong intuitions about what to focus on, where to steer the LLM versus letting it wander, and how to validate the output.

All of that said, I'm learning Rust the old way. Working my way through books, typing in code (with all AI-driven completion features turned off in my editor), using the debugger, and so on.

C is my favourite language of all time (definitely NOT C++, which I've used more than any other language but never enjoyed; no doubt due to that feeling that I could actually KNOW C, but C++ was too sprawling to fully load into my brain). So learning Rust makes sense, at least as a recreational programming activity, and I want to see if I can muster the patience and resolve to work through it like it's 1999.

Where this is likely to fall apart is a lack of an actual project. I do best with a goal, and although learning Rust is a goal, if I don't come up with a project to use it on, I'm unlikely to get very far.

We shall see what happens.
